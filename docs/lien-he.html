Liên hệ và đính chính

Bạn có thể gửi góp ý kỹ thuật, báo lỗi hoặc yêu cầu đính chính qua GitHub Issues của dự án.

Mở GitHub Issues ↗

Hãy nêu liên kết trang cần sửa, nội dung có vấn đề và nguồn đối chiếu. GitHub Issues là kênh công khai và cần tài khoản GitHub để gửi yêu cầu; không đăng thông tin cá nhân nhạy cảm, mật khẩu hoặc token.

Hiện chưa có kênh liên hệ riêng tư được công bố. Chủ dự án xem xét các yêu cầu trước khi cập nhật nội dung; không cam kết thời gian phản hồi.
